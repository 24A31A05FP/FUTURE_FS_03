# Sweet Crumbs Bakery Website

A modern and responsive bakery website created using HTML, CSS, and JavaScript.

This project was developed as part of the **Future Interns Full Stack Web Development Internship – Task 3 (2026)**.

---

# 🚀 Project Overview

Sweet Crumbs Bakery is a professional bakery website that allows customers to:

* View bakery menu items
* Explore bakery products
* Place bakery orders online
* Automatically calculate total amount
* View order history
* Cancel orders from history
* Store order history permanently using Local Storage

The website is fully responsive and designed with a modern UI.

---

# ✨ Features

## 🏠 Home Section

* Attractive bakery hero section
* Sticky navigation bar
* Smooth scrolling

## 📖 About Section

* Bakery introduction
* Professional layout

## 🍩 Menu Section

Bakery menu items with images and prices:

* Chocolate Cake
* Red Velvet Cupcake
* Strawberry Donut
* Butter Croissant
* Blueberry Muffin
* Cinnamon Roll
* Cheesecake Slice
* Fresh Bread Loaf

## 🛒 Order System

Customers can:

* Enter name
* Enter email
* Enter contact number
* Select bakery item
* Enter quantity
* Automatically calculate total amount
* Submit order

## 📜 Order History

* Stores order history permanently
* Displays submitted orders
* Cancel order option
* Removed orders disappear permanently
